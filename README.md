A compact chess engine in under 4,096 bytes of Python (3.13, standard library only) for the make.fun tiny-chess-01 bounty. It plays the house gauntlet through `MAKEFUN_ENV_URL` using a negamax alpha-beta search (depth 3) with material and mirrored piece-square evaluation under a node budget.

Run: `MAKEFUN_ENV_URL=<url> python3 main.py`
